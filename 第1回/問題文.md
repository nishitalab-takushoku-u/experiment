## 問題文

#### 1.	一桁の数字 n を入力して、n を英訳して表示するプログラム Translate.java を作成せよ。

<pre>
% java Translate
n = <i>0</i>
zero
</pre>

【実行例 2】（斜体はユーザによる入力）

<pre>
% java Translate
n = <i>1</i>
one
</pre>

#### 2.	整数 n を入力して、nが偶数ならば「n は偶数です。」、そうでなければ「n は奇数です。」と表示するプログラム Even.java を作成せよ。

【実行例 1】（斜体はユーザによる入力）

<pre>
% java Even
n = <i>5</i>
n は奇数です。
</pre>

【実行例 2】（斜体はユーザによる入力）

<pre>
% java Even
n = <i>8</i>
n は偶数です。
</pre>


#### 3.	3つの整数を小さい順に並べ替えて表示するプログラム Narabekae3.java を作成しなさい。

【実行例 1】（斜体はユーザによる入力）

<pre>
% java Narabekae3
3つの整数を入力してください。
<i>2</i>
<i>1</i>
<i>3</i>
小さい順に並べ替えると 1, 2, 3 になります。
</pre>

【実行例 2】（斜体はユーザによる入力）

<pre>
% java Narabekae3
3つの整数を入力してください。
<i>4</i>
<i>-2</i>
<i>-2</i>
小さい順に並べ替えると -2, -2, 4 になります。
</pre>
